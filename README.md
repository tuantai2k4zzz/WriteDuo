# WriteDuo

Monorepo fullstack application for WriteDuo (write-vspeak).

## Project Structure

```
write-vspeak/
├── backend/    # NestJS backend API
└── frontend/   # Next.js frontend web application
```

## Getting Started

### Backend
```bash
cd backend
npm install
npm run start:dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
